# Modern Task Manager 📝

A clean and responsive dark-themed to-do application built with pure Vanilla JavaScript, CSS3, and HTML5.

## Features
- ⚡ **Full CRUD:** Create, read, inline-edit, and delete tasks.
- 💾 **Data Persistence:** Automatically saves all tasks to `localStorage`.
- 🎨 **Dark Theme:** Minimalist UI styled with modern CSS flexbox.
- 📱 **Responsive:** Works seamlessly across desktop and mobile screens.

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
